## how to run this

1. Install dependencies by running 'python3.10 -m pip install -r requirements.txt'

2. Modify the 'ROOT' variable in .env to match the project folder path of current machine. 

3. Run the following command to execute the program:
  `python3.10 main.py --url https://app.box.com/s/rf6p81j3o507e8c5saywtlc1p91f8po9`

4. Files/Folders of the target URL will be downloaded into the folder 'downloaded_files' in the project root.
